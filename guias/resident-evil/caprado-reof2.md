# Resident Evil Outbreak File #2 · REOF2 (PS2)

Repositório: https://github.com/caprado/REOF2 · Espelho: https://github.com/alves-r/mirror-caprado-reof2

Decompilação e preservação do Resident Evil Outbreak File #2 de PS2, a partir do binário japonês `SLPM_656.92`. O port para Windows abre até o menu principal, com vídeo, áudio e controles.

| Item | Detalhe |
|---|---|
| Tipo | Decomp de pesquisa |
| Executável pronto | Não |
| Precisa de emulador | Sim, só para jogar o original: PCSX2 no Linux e no Windows ([guia](../recomp-e-emulacao/pcsx2-pcsx2.md)) |
| Você precisa fornecer | Não documentado no repositório. O README só pede uma cópia legal do jogo. ⚠️ Você indicou que não consegue dumpar PS2. |
| Arch Linux | Não documentado no repositório |
| Windows | Não documentado no repositório |
| Estado | Em andamento: 4073 funções extraídas, e só o caminho até o menu foi portado. |
| Dificuldade | Difícil (toolchain manual) |

Ainda não dá para jogar: o port só chega ao menu. **Como jogar o jogo, como alternativa:** o Outbreak File #2 original de PS2 roda no PCSX2 com a sua cópia (sugestão).

## Arch Linux

Não documentado no repositório. A raiz tem um `CMakeLists.txt`, mas o README não explica o build nem quais arquivos do jogo são necessários.

## Windows
