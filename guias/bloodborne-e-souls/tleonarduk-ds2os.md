# Dark Souls II · ds2os (PC)

## Arch Linux

1. Siga a seção Arch Linux do [guia do ds3os](tleonarduk-ds3os.md) para hospedar o servidor.
2. No `Saved/default/config.json`, troque `GameType` para `DarkSouls2` e reinicie o servidor.

## Windows

1. Siga a seção Windows do [guia do ds3os](tleonarduk-ds3os.md).
2. No `Saved\default\config.json`, troque `GameType` para `DarkSouls2` e reinicie o servidor.
