# The Legend of Zelda: Breath of the Wild · botw (Switch)

Repositório: https://github.com/zeldaret/botw · Espelho: https://github.com/alves-r/mirror-zeldaret-botw

Decompilação experimental e em andamento do Breath of the Wild v1.5.0 para Switch. O README avisa que ela **não serve para jogar**: o objetivo é entender o jogo, ajudar a caçar glitches e documentar.

| Item | Detalhe |
|---|---|
| Tipo | Decomp de pesquisa |
| Executável pronto | Não |
| Precisa de emulador | Não se aplica. O jogo original roda no Switch. |
| Você precisa fornecer | Não documentado no repositório. O README remete ao site https://botw.link. ⚠️ Você indicou que não consegue dumpar Switch. |
| Arch Linux | Não documentado no repositório |
| Windows | Não documentado no repositório |
| Estado | Experimental, em andamento. |
| Dificuldade | Difícil (toolchain manual) |

**Como jogar o jogo, como alternativa:** o README só cita o Switch. Não há port para PC conhecido.
