# Guias de instalação

Como instalar cada repositório do [`repos.txt`](../repos.txt), do zero até jogar (ou usar), no Arch Linux e no Windows. Gerado por `tools/build_index.py`; confira pendências com `python tools/check_guides.py`.

**Legenda:** ✅ nativo · 🟡 via Proton/Wine/WSL · ❌ não suportado · ❔ não documentado

> Nenhum guia indica onde baixar ROMs, ISOs, BIOS ou jogos: o arquivo pedido em cada guia tem de vir da sua própria cópia.
